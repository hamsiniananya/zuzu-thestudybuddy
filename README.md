# Zuzu 🐻

Zuzu is a little desktop buddy I’m building because studying alone gets boring.

She just sits on your screen, talks to you, judges you when you're not studying, and occasionally gives you some advice. Basically, a tiny roommate who never pays rent.

## What she can do

* Talk to you
* Give random advice
* Judge your procrastination
* React to what you do
* Stay on your desktop
* Start automatically with Windows

I'm also working on making her responses less repetitive, because hearing the same dialogue 20 times gets old pretty quickly.

## Built with

* Tauri
* Rust
* React
* TypeScript
* CSS

## Status

Still very much a work in progress.

Currently working on:

* Making Zuzu smarter
* Giving her more personality
* Adding more reactions and behaviours
* Making her less predictable

## Running it

```bash
npm install
npm run tauri dev
```

That's pretty much it.

More stuff will probably get added as I keep building her.

## Why Zuzu?

Because apparently having a tiny creature on your desktop telling you to study is more motivating than having self-discipline.
